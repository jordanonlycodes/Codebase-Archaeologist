## Commands / sandbox workaround

Normal suite: `.venv/bin/python -m pytest -q`. The existing sandbox asyncio selector
stalls without bounded polling; tests here use this process-local wrapper, with no
application-networking patch:

```bash
.venv/bin/python - <<'PY'
import selectors, pytest
Base = selectors.DefaultSelector
class Polling(Base):
    def select(self, timeout=None):
        return super().select(.02 if timeout is None else min(timeout, .02))
selectors.DefaultSelector = Polling
raise SystemExit(pytest.main(['-q', '--tb=short']))
PY
```
